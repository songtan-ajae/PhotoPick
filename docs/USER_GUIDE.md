# 포토픽 Windows v1.0.5 사용 안내

## 시작하기

릴리즈의 ZIP 전체를 압축 해제한 뒤 `photo_curator.exe`를 실행하세요. DLL, `data`, 모델·폰트·예시 사진 폴더를 함께 유지해야 합니다. Flutter 개발 도구나 Python을 설치할 필요는 없습니다.

현재 배포 대상은 Windows x64입니다. HEIC/HEIF 사진은 현재 지원하지 않으므로 원본을 보존하고 지원 형식으로 변환한 사본을 사용하세요. 모바일 기본 갤러리와 macOS 배포는 향후 범위입니다.

현재 파일은 코드 서명되지 않았습니다. Windows가 경고하면 출처와 SHA-256을 확인하세요. 보안 기능을 끄거나 경고를 무조건 무시할 필요는 없습니다. `VCRUNTIME140.dll` 또는 `MSVCP140.dll` 오류가 발생하면 [Microsoft 공식 Visual C++ x64 런타임](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)을 확인하세요.

## 정리 순서

1. 사진 폴더를 선택하고 분석이 끝날 때까지 기다립니다.
2. 한 장씩 고르려면 검토 화면을 엽니다. **왼쪽은 보관, 오른쪽은 삭제 대기**입니다. Windows에서는 좌우 방향키와 화면 버튼으로도 선택할 수 있습니다. 되돌리기는 화면 버튼 또는 Ctrl+Z를 사용합니다.
3. 먼저 자동으로 나누고 싶다면 `AI 추천대로 정리하기`를 선택하고 적용을 확인합니다. 보관·삭제 대기로 바로 분류되며 완료 후 필요한 결과만 다시 검토할 수 있습니다.
4. 삭제 대기 화면에서도 스와이프로 다시 고를 수 있습니다. 삭제 대기는 분류 상태일 뿐 원본을 삭제하지 않습니다. 실제 파일 이동은 별도의 확인을 거쳐 Windows 휴지통으로 진행합니다.

사진 정리 전 원본을 따로 백업해 두는 것을 권장합니다. 앱은 자동으로 실제 삭제를 실행하지 않습니다.

## 취향을 알려주는 방법

비슷한 촬영본이 있으면 비교 화면에서 마음에 드는 사진을 선택합니다. 그렇지 않으면 잘 찍혔다고 생각하는 내 사진 여러 장을 골라 취향 예시로 등록합니다.

설정의 `사용자 취향 반영 정도`에서 강도를 조절합니다. 100%로 선택해도 실제 추천의 취향 비중은 최대 80%입니다. 학습 사진 수와 사용 가능한 특성에 따라 실제 반영이 줄어들 수 있습니다. 사진 아래 취향 유사도는 비슷한 정도를 나타내며, 품질 점수나 선택 강도와 다른 값입니다.

초점·흐림·저해상도 같은 기본 결함 검사를 먼저 적용합니다. 다만 모든 결함을 정확히 판별할 수는 없고 야간 촬영·의도적 흐림·특수한 사진에서는 오판이 있을 수 있습니다. 모델 실행이 불가능하면 로컬 품질 기준으로 전환되며 화면에서 상태를 확인할 수 있습니다.

## 다시 시작하기와 설명

- `처음부터 다시하기`: 현재 사진 폴더의 분류를 초기화합니다. 원본 사진과 취향 프로필은 보존합니다.
- `취향 초기화`: 취향 학습 내용을 별도로 초기화합니다. 화면의 확인 안내를 읽고 실행하세요.
- 기본 설명은 예시 사진과 쉬운 표현으로 안내합니다. 설정의 `더욱더 자세히 설명하기`에서는 수식·전문 용어·모델 폴백·계산 한계를 확인할 수 있습니다.

## 다운로드 무결성 확인

릴리즈에 게시된 `SHA256SUMS.txt` 값과 다음 PowerShell 결과를 비교하세요.

```powershell
Get-FileHash -LiteralPath '.\PhotoPick-v1.0.5-win-x64-public.zip' -Algorithm SHA256
```

문제가 생기면 [GitHub Issues](https://github.com/songtan-ajae/PhotoPick/issues)에 버전과 재현 순서를 남겨 주세요. 개인 사진·경로·분류·취향 데이터는 제출하지 않아도 됩니다.
